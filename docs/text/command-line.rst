Command-line reference
======================

The ``pyopmnearwell`` command generates near-well OPM Flow decks, runs OPM
Flow, or performs both steps. This reference documents the syntax, defaults,
validation rules, output behavior, and common combinations supported by the
current command-line parser.

.. code-block:: console

   pyopmnearwell [OPTIONS]

Display the built-in help:

.. code-block:: console

   pyopmnearwell --help
